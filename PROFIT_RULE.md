## PROFIT-FOCUSED FEATURES

### 1. **Profit Dashboard** (Auto-displays after launch)
- **Real-time profit tracking**: Shows total profit, profit %, invested, current value
- **Birdeye chart integration**: Live price chart embedded on the same page
- **Wallet status table**: See exactly which wallets have sold vs holding
- **Quick action buttons**: Instant buy/sell without leaving the dashboard
- **Auto-refresh**: Updates every 2 seconds to track profit in real-time

### 2. **Quick Buy/Sell** (Main wallet from .env)
- Uses main wallet from `.env` for instant trades
- No need to specify wallet address - automatically uses profit wallet
- One-click execution for maximum speed
- Perfect for catching pumps or taking profits

### 3. **Auto-Switch to Profit Dashboard**
- After token launch, automatically switches to Profit Dashboard
- No manual navigation needed - see profit immediately
- Focus stays on profit tracking

### 4. **Real-Time Wallet Status**
- See which bundler wallets have auto-sold
- Track which wallets are still holding
- Individual wallet profit tracking
- Quick sell buttons for individual wallets
